About

Testing as a craft, not a checkbox

I'm a senior QA automation engineer based in Bitola, North Macedonia, with 10+ years turning fragile manual test cycles into pipelines a team can actually rely on. My background spans high-traffic US e-commerce — order flows from cart through fulfillment and returns, a suite of roughly 800 UI and API tests parallelized from a 32-hour run down to 3 — and, more recently, UK education software, where TestCafe is now my primary framework with Playwright alongside it.

I lead by building: test plans and frameworks first, and increasingly, AI-assisted tooling. Shift Board, a workflow board I built wrapping Claude Code and other AI providers with MCP tracker integrations, is the clearest expression of that — letting QA engineers work through their trackers with agentic help instead of around them.
